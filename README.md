# Vantage

Compartilhamento de tela + áudio de **baixa latência** (60fps) entre PCs via
LAN ou VPN (Radmin / Hamachi).

## ⬇️ Baixar — versão 1.0.0

**[Vantage-1.0.0-win-x64.zip](https://github.com/caduwinter/vantage-releases/releases/download/v1.0.0/Vantage-1.0.0-win-x64.zip)** · Windows x64 · portátil

1. Extraia o zip e rode `Vantage.exe`.
2. Clique em **Configurar agora** (um aviso de administrador, uma vez só).
3. Adicione o IP Radmin dos seus amigos.

Quem não quiser baixar pode assistir pelo navegador em `http://IP-DO-HOST:8080/`.
